## Brain vault
Project knowledge lives in the `{{vault}}/` vault (Obsidian). Before searching code:
1. Read `{{vault}}/{{hub}}.md`, then the index of the folder that fits (`{{vault}}/<Folder>/<Folder>.md`).
2. If that is not enough, grep `^description:` in `{{vault}}/`.
3. Open at most 3 notes, then the paths in their `code:` and `source:` fields. Search the code only if the notes do not answer.
When a task is done, write it down with `/engram:note`. The vault stays on this machine in local git; never add a remote.
